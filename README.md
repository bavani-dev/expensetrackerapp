# 💰 Expense Tracker App

A stylish Flutter Expense Tracker application designed to help users manage their daily expenses, income, budgets, and financial activities in one place.

## 📱 Features

- 🏠 Dashboard / Home
- 💸 Add and manage expenses
- 💰 Track income
- 📊 Monthly budget management
- 👤 User profile
- 🧾 Attach receipt or bill images
- 🔔 Expense and reminder notifications
- 💾 Local data storage
- 🇮🇳 Indian Rupee (₹) currency support
- 🎨 Modern Material 3 user interface

## 🛠️ Technologies Used

- Flutter
- Dart
- Provider
- SharedPreferences
- Flutter Local Notifications
- Image Picker
- FL Chart
- Google Fonts
- Lottie
